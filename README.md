# 💱 Currency Converter App

A modern and responsive **Currency Converter Web Application** built using **HTML, CSS, JavaScript, and Currency Exchange API**. This project allows users to convert values between multiple currencies with real-time exchange rates and an easy-to-use interface.

---

## 📌 Features

✅ Convert between **Multiple Currencies**
✅ Real-time exchange rates using **JavaScript API**
✅ **Swap Functionality** to instantly exchange currencies
✅ Enter **Custom Amount** for conversion
✅ Dynamic currency selection
✅ Responsive and clean UI
✅ Fast and simple conversion process

---

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsiveness
* **JavaScript (ES6)** – Conversion logic and API integration
* **Currency Exchange API** – Fetch real-time exchange rates

---

## 🚀 How It Works

1. Enter the amount you want to convert.
2. Select the source currency.
3. Select the target currency.
4. Click **Convert**.
5. View the converted amount instantly.
6. Use **Swap** button to switch currencies quickly.
